# 🌐 Projeto Tailwind CSS

Projeto desenvolvido com foco no aprendizado e na aplicação prática do **Tailwind CSS**, explorando a construção de interfaces modernas, responsivas e reutilizáveis utilizando uma abordagem baseada em classes utilitárias.

O desenvolvimento foi realizado com o apoio do curso **Tailwind CSS**, da [Origamid](https://www.origamid.com/curso/tailwind-css/), utilizando os conceitos apresentados durante as aulas e adaptando-os para a criação deste projeto.

## 🛠️ Tecnologias

* HTML5
* CSS3
* Tailwind CSS
* JavaScript

## 🎯 Objetivos

O principal objetivo deste projeto foi consolidar conhecimentos em Tailwind CSS por meio da prática, desenvolvendo uma interface completa e explorando diferentes recursos oferecidos pelo framework.

Além disso, o projeto faz parte da minha evolução no desenvolvimento **Front-End**, buscando ampliar meu domínio de ferramentas utilizadas no desenvolvimento de interfaces modernas.

## 💻 Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git
```

Acesse a pasta:

```bash
cd SEU-REPOSITORIO
```

Caso o projeto utilize dependências do Node.js:

```bash
npm install
```

Execute o projeto conforme a configuração utilizada.

## 📈 Aprendizados

Este projeto contribuiu para meu desenvolvimento principalmente nos seguintes pontos:

* Maior familiaridade com Tailwind CSS
* Criação de layouts responsivos
* Utilização de classes utilitárias

* Desenvolvimento de componentes visuais
